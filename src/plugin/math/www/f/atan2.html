atan2 - Angle toward a given point

plugin math;
atan2( y:number, x:number ) :number
This is part of the math plugin. You must load the plugin via either -lmath on the shell command line, or a plugin math; line in a script.

Returns the angle toward a given point. This is similar to atan(y/x) except that atan2 takes the signs of x and y into account to select the correct quadrant, and it can handle vertical lines (where y is 0).

Examples
atan2(1,-2) 2.67794504459 From the signs of the arguments, the function knows the angle must be in the 4th quadrant.
function aim(x,y){return {distance:hypot(x,y), bearing:(Math.PI + atan2(-x,-y)) / Math.PI * 180}; } aim(1,1) {"distance":1.41421356237,"bearing":45} aim(-3,4) {"distance":5,"bearing":323.130102354} aim(0,-17) {"distance":17,"bearing":180} This defines an aim() function to return the distance and bearing to a given point. The bearing is returned in degrees, not radians. It is measured clockwise from the Y axis instead of counterclockwise from the X axis. atan2() normally returns a radian value in the range [-π, π), but we don't want negative bearings. Swapping x and y, negating them, and adding Math.PI fixes all of that. A bit of arithmetic converts radians to degrees, and we're done.
