floor - Floor (round down)

plugin math;
floor( n:number ) :number
This is part of the math plugin. You must load the plugin via either -lmath on the shell command line, or a plugin math; line in a script.

Returns the floor (round down) of n.

Examples
floor(1.4) 1
[-1.4,1.4,1.6] # {this,floor(this),ceil(this),round(this),trunc(this)}
thisfloor(this)ceil(this)round(this)trunc(this)
-1.4-2-1-1-1
1.41211
1.61221
 This example shows all four of the rounding functions.
