Readline Plugin

This uses the GNU ReadLine library for interactively reading command from the user. This is an alternative to the "line" plugin.

Options   Functions   Commands   Other Features

Options

The readline plugin doesn't add any new options.

Functions

The readline plugin doesn't add any new functions.

Commands

The readline plugin doesn't add any new commands.

Other Features

The readline plugin offers editing, history, and name completion. Name completion is attempted when you hit the <Tab> key after a partial name.

GNU ReadLine was used in edj before the fineline library was written, and remains available via this plugin for any user who prefers it.

The fineline library adds a number of useful new features, but the killer reason that fineline was necessary is that ReadLine doesn't work inside an ncursesw program. I couldn't find any line input library that could do that, but the screen plugin requires it.
