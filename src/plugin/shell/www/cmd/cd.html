cd - Change the working directory

cd directory
This changes the working directory. If the new directory is not accessible or doesn't exist, this will fail. Changes relative to the current working directory work as expected; for example "cd .." moves up one directory.
Examples
cd sampledata This changes the working directory from "/home/steve/proj/jx" to "/home/steve/proj/jx/sampledata". Note that the command doesn't output anything unless there's an error.
