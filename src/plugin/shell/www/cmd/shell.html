shell - Run an external program

shell commandline
The shell command passes its arguments to the system shell, and displays the output.
Examples
shell uname -a Linux sampo 5.14.21-150400.24.100-default #1 SMP PREEMPT_DYNAMIC Mon Dec 4 19:12:13 UTC 2023 (3f5cd84) x86_64 x86_64 x86_64 GNU/Linux This runs "uname -a" via the system shell, and displays its output.
Notes
  • The command's entire parameter text is treated as a single string to be executed via the shell. The command ends at the next ";" or "}" character, or at the end of the input. Since the shell command is likely to be used interactively, this means run can run anything that doesn't require a ";" or "}" very conveniently.
  • The external program's stdout is redirected to a pipe, which jx reads and displays it. The good news is that this means the shell command works even when run in a window, e.g. with the -lscreen plugin. The bad news is that interactive programs such as text editors might have issues.
  • If you want to compute the command string instead of using literal text, consider using the readShell() function.
