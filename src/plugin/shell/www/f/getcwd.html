getcwd - Return the current working directory

getcwd():string
This is part of the shell plugin. You must load the plugin via either -lshell on the shell command line, or a plugin shell; line in a script.

This returns the current working directory, as a string.

Examples
getcwd() "/home/steve/proj/edj" This simply returns the current working directory, as a string.
Notes
  • If all you want to do is display the current working directory, then the pwd command is slightly more convenient.
