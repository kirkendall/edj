readShell - Run an external program and return its output

readShell(command:string):string
This is part of the shell plugin. You must load the plugin via either -lshell on the shell command line, or a plugin shell; line in a script.

This function runs an external program via the system shell, and returns the result. The entire command line should be passed as a single string. It may use redirection, pipes, environment variables, quoting... all that fun stuff.

Examples
readShell("uname -s") "Linux" Run the "uname" program with a "-s" flag (to fetch the kernel name) and collect its output into a string. Trailing newlines are trimmed, so they don't pollute single-line results such as this.
Notes
  • If the program tries to read from stdin, or write to stderr, the results are undefined.
  • Trailing newlines are trimmed. Usually that's a good thing.
