shellQuote - Add quoting to make a string safe to pass as a shell command argument

shellQuote(data:any):string
This is part of the shell plugin. You must load the plugin via either -lshell on the shell command line, or a plugin shell; line in a script.

This function adds quoting, if necessary, to make data safe to pass as part of a shell command line, e.g. for use with the readShell() function. It is mostly intended for strings, but it will also convert other data types to string in the manner of the toString() function.

Values that consist entirely of ASCII letters, digits, ".", "/", and "-" are left unchanged. They don't require quoting.

Other values will be wrapped in apostrophe quotes, and any instances of apostrophes or backslashes in the value will be escaped with a backslash. Non-ASCII characters don't receive any special treatment.

Examples
shellQuote("sample.json") "sample.json" This string didn't need quoting.
shellQuote("Don't press that button!") "'Don\\'t press that button!'" print shellQuote("Don't press that button!") 'Don\'t press that button!' This time the value is quoted by enclosing it in apostrophes. Since it also contains a literal apostrophe, that apostrophe is escaped by a backslash. Displaying this as a JSON string can obfuscate what's happening here, so we also use the print command to output it as plain text.
shellQuote(42) "42" shellQuote({foo:true}) "'{\"foo\":true}'" print shellQuote({foo:true}) '{"foo":true}' Some quick examples to show that non-string values can be handled too. In particular, numbers don't need quoting when converted to strings. Complex values are output as JSON.
Notes
  • Values that start with a "-" (including negative numbers) could be mistaken for an option by some programs, in some contexts. I'm sorry for sounding so vague about this, but the vagueness is the point: No simple quoting function can protect against this. You need to adjust your command line to reflect what you're trying to do. For example, if you want to remove a file named "-f", the way to do it is "rm ./-f". In bash's "[" tester command, if you want to compare a string to a value that starts with "-", the usual way to do this is to prefix both strings with "X", as in "[ "X$1" = "X-s" ]".
