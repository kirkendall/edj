Shell plugin - Runs external programs via the system shell

The shell plugin adds the ability to run external programs. This is a huge security risk, so load this plugin with caution!

Options   Functions   Commands   Other Features

Options

The shell plugin doesn't add any options.

Functions

Function Description
readShell() Runs a program via the system shell, and returns the output. Trailing newlines are trimmed.
getcwd() Returns the current working directory, as a string.

Commands

Command Description
shell Runs an external command via the system shell.
cd Change the working directory.
pwd Print the current working directory.

Other Features

The shell plugin doesn't add any other features.
