writeXML - Write data to a file in XML format

writeXML(data:object, filename:string):null
This is part of the xml plugin. You must load the plugin via either -lxml on the shell command line, or a plugin xml; line in a script.

The writeXML() function writes data to a file in XML format. It always returns null.

Examples
{foo:"bar"}.writeXML("foo.xml") null The simplest possible example. The key "foo" becomes a tag name, and the value "bar" becomes the content. The null return value means it was written successfully; if there were any errors then it would return an error message instead.
{`?xml_`:{version:"1.0"},config}.writeXML("config.xml") null Here we're writing edj's config object out as XML. Each member of the object passed to writeXML() gets written separately, so most objects have just one member containing all of the actual content, and maybe also a `?xml_` member to generate a <?xml version="1.0"> header tag.
Notes
  • The text that's written to the file is basically the same as the string returned by toXML() when used without a template. A newline is added at the end to keep text editors happy.
  • This respects the samepretty and tab settings that affect JSON. Usually the pretty option is set, but running set nopretty before calling writeXML() will cause the generated XML to be compact instead of prettified.
