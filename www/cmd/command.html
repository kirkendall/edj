command - Define a function that can be used like a command

command name { cmds }
command name (args) { cmds }
This defines a function. It is basically the same as the function command except for two big differences:
  • You can use the defined function like a command. If the function name appears at the start of a command and isn't immediately followed by a "(" then the rest of the command line is used as the function parameters. If the function returns null (or doesn't use return at all), that will be suppressed but other return values will be shown.
  • You can define commands without a parameter list. Later, when you invoke the function as a command, the rest of the command line is used as literal text and is passed to the function. You can use the "this" variable to access the text.
Examples
command area(width, height) { return width * height; } area 2+2, 3 12 1 + area(2+2, 3) 13 We define a simple "area" command/function which returns the area of a rectangle. Then we invoke it like a command. Note that the arguments are still parsed as a comma-delimited list of expressions to evaluate before being passed to the function.

After that, we also call it like a normal function, just to show that it really is a function.

command echo { print this, "\n"; } echo Hello, world! Hello, world! echo(42) 42
null First we define an "echo" command which prints its argument. Then we invoke it with the command-line arguments "Hello, world!" which are passed into it as a literal string, since we defined echo without a parameter list. And since the function doesn't use return, it effectively returns null, which is suppressed so we only see the output that the body of the function explicitly printed.

And again we follow that with a more normal function invocation just to show that this too is still truly a function. The null that it returns is not suppressed when used as a normal expression.

Notes
  • Just to be clear: Functions defined via function and functions defined via command share the same namespace. You can't define a function and a command with the same name.
  • The function command can describe functions, but the command command can't. Happily, you can use function to describe functions that were defined with command
    function echo command echo Not much to say about "echo" except that it's a command.
  • Why not simply allow all functions to be used as commands? Because it could get confusing.
    const pi=3.14 pi null Pretending that all functions are useable as commands! Here we define pi and try to output it, but "pi" could refer to the parseInt() function because the first letter and all uppercase letters match, so edj would would think you were invoking parseInt() without an argument, so it returns null as a gentle error result. You'd expect 3.14 but you'd get null. This is why edj doesn't do that.
