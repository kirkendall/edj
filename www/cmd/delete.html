delete - Delete a variable, or part of a variable

delete lvalue
This deletes a variable or part of a variable. The "lvalue" argument is any expression which could appear on the left side of an = assignment operator.
Examples
var a=1...5, o={length:42,width:17,height:28,sanctity:12}; delete a[3] a [1,2,3,5] delete o.sanctity o {"length":42,"width":17,"height":28} delete o o null First we define a couple of variables to play with. Then we delete a[3] which is the fourth element since array indexing starts at 0. Printing a shows that the "4" was deleted.

Similarly, we delete o.sanctity and output the remaining parts of o. Lastly, we delete o entirely, so attempting to access it simply returns null instead.

for (expr = (accounts@password).expr) delete accounts[[expr]].password This shows how you could search through a large data structure ("accounts") for objects containing a "password" member, and then delete that member from each one.
Notes
  • At some point, I'd like to implement an SQL-like "delete from table where expression" but that hasn't happened yet. However, the two syntaxes don't clash; having a JS-like "delete" won't prevent me from adding an SQL-like "delete" later.
  • I've also toyed with the idea of making "delete array[]" delete the last element of an array, as a counterpart to "array[] = expr" to append to an array. But that isn't implemented yet either. You can use "delete array[-1]" though.
  • In JavaScript, delete can delete parts of variables but not the entire variable. edj lets you delete the entire variable.
