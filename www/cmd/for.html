for - Loop over the elements of an array

for (array) cmd
for (variable = array) cmd
for (variable of array) cmd
for (var variable = array) cmd
for (var variable of array) cmd
for (const variable = array) cmd
for (const variable of array) cmd
This executes cmd for each element of array.

Within cmd the value of the current element is available via the variable named after the "("; if you don't name a variable, then it will be available as "this". The var or const keyword declares a new variable with the new name; if you give a variable name without var then it must have already been declared before the for()... command.

Examples
for (var i = 1...5) { i * 2; } 2

10 The expression "1...5" returns the array [1,2,3,4,5] The for command loops over that array, setting i to each element's value while it executes the body of the loop. The body just outputs i*2.
Notes
  • Using the i...j operator is a great way to loop over a range of integer values. It is efficient, because ... uses a deferred array for the integers instead of creating all of the array elements before the loop even begins.
  • The "=" and "of" symbols both do exactly the same thing here. Most C-like languages (other than C itself) use "in" to loop over the values of an array, but JavaScript uses "in" to loop over the subscripts of an array instead of the values, which is much more cumbersome. JavaScript later added "of" to loop over values as an afterthought, but it's still weird. edj supports "of" for cross-compatibility, but "=" is more intuitive.
  • The traditional for(initialize; test; increment) version of the for-loop is not supported by edj at this time. The big obstacle here is that initialize and increment would need to be comma-delimited lists of statements (which just isn't done anywhere else in edj), and even then there's no "++" operator. Lots of pieces missing.
