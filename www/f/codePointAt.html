codePointAt - Convert characters in a string to Unicode code points

codePointAt(str:string, index?:number|array|true=true)
This is identical to charCodeAt().
Notes
  • This function exists to avoid an incompatibility with JavaScript. JavaScript uses UTF-16 character encoding internally, and the charCodeAt() function returns a UTF-16 character (potentially half of UTF-16 surrogate pair) while codePointAt() decodes surrogate pairs to return a full Unicode code point. However, edj uses UTF-8 internally (part of the JSON standard) so the distinction makes no sense.
