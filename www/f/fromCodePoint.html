fromCodePoint - Convert Unicode code points into a string

fromCodePoint(code:number|array, ...)
This is identical to fromCharCode().
Notes
  • This function exists to avoid an incompatibility with JavaScript. JavaScript uses UTF-16 character encoding internally, and the fromCharCode() function converts numbers to single a UTF-16 character (potentially half of UTF-16 surrogate pair) while fromCodePoint() always generates whole Unicode characters. However, jx uses UTF-8 internally (part of the JSON standard) so the distinction makes no sense.
