levenshtein - Measure the similarity of two strings

levenshtein(s1:string, s2:string, ignorecase?:boolean=false)
This function measures how similar or different two strings are. It returns the number of characters that must be inserted, deleted, or changed to convert one string to the other. If two strings are identical, this function returns 0. If they have no characters in common at all, then it will return the length of the longer string. In between values indicate varying levels of similarity.
Examples
levenshtein("kitten", "sitting") 3 Change "k" to "s", change "e" to "i", and insert "g". That's three edits.
levenshtein("burger", "salad") 6 These words have no characters in common, so the length of the longer string is returned.
levenshtein("Johanson", "JOHANSEN", true) 1 This uses true to make it case-insensitive, so the only difference is "o" becoming "E".
Notes
  • The reason that two strings with no characters in common will return the length of the longer string is a natural consequence of the way it's computed. In the "burger"/"salad" example, we could change "b" to "s", "u" to "a", and so on and then delete "r" for a total of 6 edits.
  • If you want to scale the result, divide it by the length of the longer string.
    function scaledlev(s1,s2) { return levenshtein(s1,s2) / max([s1.length,s2.length]); } scaledlev("kitten","sitting") 0.428571428571 scaledlev("Johanson","Johansen") 0.125
