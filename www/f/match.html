match - Find a match within a string

match(str:string, search:string, ignorecase?:boolean=false):array|null
match(arg, search:regex):array|null
The match() function searches through str for any text that matches search, and returns the first match as the first element of an array.

The search value can be either a literal string, or a regular expression. Either way, it's normally case-sensitive but you can make it ignore uppercase/lowercase distinctions by adding a true parameter (when search is a string) or by adding an "i" flag to the regular expression. You can also add a "g" flag to a regular expression to return all matches.

If doing a global search for a regular expression (by appending "g" after a regular expression) then the array will contain all matching instances. When using a regular expression without "g", if the regular expression contains any subexpressions (parentheses in the regular expressed) then the text that matched the subexpressions will be included in the result array. If there are no matches, it returns null.

Examples
"Once upon a time".match("on", true) ["On"] This finds "On" at the start of "Once". We added true after the search string to make it search case-insensitively.
"Once upon a time".match(/[aeiou]/i) ["O"] "Once upon a time".match(/[aeiou]/ig) ["O","e","u","o","a","i","e"] The first example finds the first vowel. Since search is a regular expression, we made it be case-insensitive by appending an "i" flag after the regular expression. The second example finds all vowels by also appending a "g" flag.
"Once upon a time".match(/p(.)n/) ["pon","o"] This time we're using a regular expression that uses a subexpression. The result array includes both the full matching text "pon", and the text "o" that matched the subexpression.
Notes
  • If you use a regular expression and add a "g" flag, then it will find all matches (like matchAll()) instead of just the first.
  • Just to repeat: If no match is found, this returns null instead of an empty array. edj does this because JavaScript also returns null and we're trying to avoid unnecessary incompatibilities.
