matchAll - Find all matches within a string

matchAll(str:string, search:string, ignorecase?:boolean=false):array|null
matchAll(arg, search:regex):array|null
The matchAll() function searches through str for any text that matches search, and stores the matches in an array. If there are no matches, it returns null.

The search value can be either a literal string, or a regular expression. Either way, it's normally case-sensitive but you can make it ignore uppercase/lowercase distinctions by adding a true parameter (when search is a string) or by adding an "i" flag to the regular expression.

Examples
"Once upon a time".matchAll("on", true) ["On","on"] This finds "On" at the start of "Once" and "on" at the end of "upon". We added true after the search string to make it search case-insensitively.
"Once upon a time".matchAll(/[aeiou]/i) ["O","e","u","o","a","i","e"] This finds all of the vowels. Since search is a regular expression, we made it be case-insensitive by appending an "i" flag after the regular expression.
Notes
  • Just to repeat: If no match is found, this returns null instead of an empty array. jx does this because JavaScript also returns null and we're trying to avoid unnecessary incompatibilities.
  • JavaScript gets weird when you search for a plain string. Instead of returning an array, it returns a RegExpStringIterator object. Since jx doesn't have classes, it just returns an array.
