padEnd - Add padding to the end of string

padEnd(subject:string, len:number, pad?:string=" "):string
The padEnd() function adds characters to the end of the subject string, to make its overall length be len characters. By default, it adds space characters but you can pass some other string to use for padding instead.
Examples
"Chapter 3".padEnd(20, " . ")+"page 21" "Chapter 3 . . . .page 21" This appends multiple copies of the " . " string to "Chapter 3", to give it the overall width of 20 characters. Then it appends "page 21". Note that " . " is 3 character long but we only needed 17 characters of padding, so the last instance only added 2 of the 3 characters.
Notes
  • This pads by character length (count), not by character width. This means text containing composed diacritics, CJK characters, or emoji won't line up properly.
