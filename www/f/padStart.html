padStart - Add padding to the start of string

padStart(subject:string, len:number, pad?:string=" "):string
The padStart() function adds characters to the start of the subject string, to make its overall length be len characters. By default, it adds space characters but you can pass some other string to use for padding instead.
Examples
98.6.toFixed(2).padStart(10) " 98.60" This formats the number 98.6 as a string with two digits after the decimal, and then pads the string on the right to an overall width of 10 characters. Padding like this can be handy for making decimal points line up when using toFixed() or money() in a table column.
Notes
  • This pads by character length, not by character width. This means text containing composed diacritics, CJK characters, or emoji won't line up properly. It should work okay for numbers though.
