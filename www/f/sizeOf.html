sizeOf - Count the internal memory bytes used by a given value

sizeOf( arg:any ) :number
Counts the bytes of RAM needed to store a parsed JSON value.
Examples
sizeOf({name:"Michael Jordan",number:23}) 192
Notes
  • Honestly, this doesn't have much practical use. Maybe it'll help you get a feel for how much RAM you need to load a document, but remember deferred arrays use very little RAM.
    sizeOf(1...1000000) 96 A million-element array fits in just 96 bytes, because the ... operator returns a deferred array.
