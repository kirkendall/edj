toString - Convert any value to a string

toString( arg:any ) :string
Returns a string version of arg.

If arg is already a string, it is returned unchanged. In particular, quotes will not be added, and no backslash escapes will be used.

Conversion of anything else is converted as JSON text, similar to the stringify() function. For numbers, booleans, and null this is trivial, but it can also handle objects and arrays.

Examples
toString("2024-10-31") "2024-10-31" Dates are strings, so they're returned unchanged.
toString(null) "null" Numbers and symbols are easy to convert.
toString({foo:2+2}) "{\"foo\":4}" Arrays and objects are converted to JSON. The backslashes shown in the response are not part of the string, that's just how edj displays strings. The same is true for the outermost set of quotes.
Notes
  • This is different from JavaScript's various toString() member functions. For objects, JavaScript returns the string "[object Object]" which is useless. For arrays, JavaScript returns the contents of the array without brackets, and with unquoted strings.

    If you need edj to return a JavaScript-style string for arrays, consider using join().
