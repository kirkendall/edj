Bit shift operators

Left
Operand		OperatorRight
Operand		Description
number<<numberShift a number's bits leftward
number>>numberShift a number's bits rightward
This are low-level bit shifting operators. The left argument is a binary integer to be shifted, and the right argument is the number of bits to shift, which must be a non-negative integer.
Examples
27 << 1 54 27 >> 1 13 Shifting to the left by one bit multiples a value by 2. Shifting to the right by one bit divides by two and discards the least significant bit (so we get 13 instead of 13.5).
Notes
  • One fairly common use for these is to left-shift "1" to a given bit position.
    1 << 5 32 The fifth bit in a binary number is the 32's bit.
