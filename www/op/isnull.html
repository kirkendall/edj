IS NULL operators

exprIS NULLTrue if expr is null
exprIS NOT NULLFalse if expr is null
These compare an expression to null.
Examples
glorxpik is null true If there is no variable named glorxpik, then it'll be treated as a null value, and the is null operator can detect that.
1/0 is null true Errors are represented internally as null with the error details embedded in them. The IS NULL operator sees the null and hides the error.
Notes
  • These operators exist mostly for SQL compatibility. Honestly, I'd rather just use === null or !== null.
  • Eventually I expect to make TypeScript-style types actually work, and replace IS NULL with a generic IS type operator. Since "NULL" is a perfectly valid type specifier, IS NULL will still work albeit in a different, more versatile way.
  • It's worth noting once again that since standard JavaScript symbols such as undefined and NaN aren't valid in JSON, edj uses null to represent exceptional conditions and errors.
